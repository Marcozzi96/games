# Joystick Touch Flottante — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aggiungere alla shell un joystick touch flottante (thumbstick che compare dove poggia il dito) e attivarlo per Pac-Man al posto del pad a pulsanti.

**Architecture:** Il joystick vive in `CollegaInput` (`src/core/input.ts`) come modalità opt-in `joystick: true`: gli eventi pointer del canvas (con `setPointerCapture`) guidano una base+knob creati al `pointerdown` e rimossi al rilascio; l'asse dominante del vettore dito (oltre deadzone 20px) viene emesso come comando direzionale discreto, solo al cambio di direzione. `screen.ts` passa il flag dal `Gioco`; la CSS posiziona l'overlay dentro `.canvas-wrap`.

**Tech Stack:** TypeScript strict, Vitest + jsdom, Vite.

**Spec:** `docs/superpowers/specs/2026-11-10-joystick-design.md`

## Global Constraints

- No semicoloni, `void` esplicito sui return, `import type`, alias `@/*` → `./src/*` (convenzioni del progetto).
- **Deadzone: 20px CSS** sul `hypot(dx, dy)` del vettore dito — sotto non si emette nulla.
- **Geometria CSS:** base ⌀ 96px, knob ⌀ 40px, spostamento knob clampato a **28px CSS** max.
- Direzione = asse dominante: `|dx| > |dy|` ⇒ sx/dx, altrimenti su/giu.
- **Emissione solo al cambio di direzione**; memoria della direzione azzerata al rilascio (un nuovo gesto ri-emette la stessa direzione).
- `joystick: true` ⇒ **nessun pad a pulsanti** e **nessun gestore `punta`/swipe** sul canvas (il joystick vince).
- Comandi emessi: solo quelli dichiarati dal gioco (filter su `dichiarati`).
- Il primo `pointerdown` del joystick chiama `audio.inizia()`.
- Solo il primo pointer è gestito; il secondo dito è ignorato.
- `smonta()` rimuove tutti i listener e gli elementi `.joystick` dal DOM.
- I giochi non toccano il DOM: tutta la gestione è della shell.

## Review Focus

1. **Secondo dito durante un gesto attivo** → ignorato; il suo `pointerup` non emette nulla → test Task 1 "secondo pointerdown durante il gesto".
2. **`pointercancel` (OS annulla il touch)** → trattato come rilascio: stick rimosso dal DOM, memoria della direzione azzerata → test Task 1 "pointercancel".
3. **Oscillazione rapida del dito (molti `pointermove`)** → al massimo un'emissione per ogni vero cambio di direzione, mai spam → test Task 1 "oscillazione rapida".
4. **Gioco con `swipe-*` dichiarati + joystick attivo** → i gesti sono tutti del joystick; gli swipe non vengono mai emessi → test Task 1 "swipe + joystick: priorità".
5. **Teardown durante un gesto attivo** → nessun listener orfano, nessun elemento `.joystick` residuo nel DOM → test Task 1 "teardown".

  - Costanti `input.ts`: `SOGLIA_JOYSTICK = 20`, `MAX_SPOSTAMENTO_KNOB = 28`.

2. `src/core/input.ts`:
   - `CavalcaturaInput`: aggiungere `joystick?: boolean;`.
   - Costanti: `const SOGLIA_JOYSTICK = 20;` e `const MAX_SPOSTAMENTO_KNOB = 28;` (px CSS).
   - In `CollegaInput({ canvas, comandi, pad = true, joystick = false, onComando })`:
     - `pulsanti`: se `joystick` è true, lista vuota (nessun pad).
     - Gestori canvas: se `joystick` → registrazioni del joystick al posto di quelle di `punta`/swipe (mutua esclusione):
       - Stato: `stick: { id: number; x0: number; y0: number } | undefined` e `ultimoDir: Comando | undefined`.
       - `pointerdown`: se `stick` definito → return (secondo dito). Altrimenti `e.preventDefault()`, `iniziaAudio()`, `canvas.setPointerCapture(e.pointerId)` in try/catch, `stick = { id, x0: e.clientX, y0: e.clientY }`; creare l'elemento `.joystick` (con child `.joystick-knob`), `style.left/top` = `e.clientX - rect.left` / `e.clientY - rect.top` (da `canvas.getBoundingClientRect()`), append a `canvas.parentElement ?? canvas`.
       - `pointermove`: se `e.pointerId !== stick.id` → return. `dx = e.clientX - stick.x0`, `dy = e.clientY - stick.y0`, `m = Math.hypot(dx, dy)`. Spostare il knob: `k = m > MAX_SPOSTAMENTO_KNOB ? MAX_SPOSTAMENTO_KNOB / m : 1`; `knob.style.transform = translate(${dx * k}px, ${dy * k}px)`. Emissione: se `m < SOGLIA_JOYSTICK` → return; `dir = |dx| > |dy| ? (dx > 0 ? 'dx' : 'sx') : (dy > 0 ? 'giu' : 'su')`; se `!dichiarati.has(dir)` o `dir === ultimoDir` → return; `ultimoDir = dir`; `onComando(dir)`.
       - `rilasciaJoystick` (su `pointerup` e `pointercancel`): se `e.pointerId !== stick.id` → return; `stick = undefined`, `ultimoDir = undefined`, rimuovere l'elemento `.joystick` dal DOM.
     - `smonta()`: oltre all'attuale, se `stick` presente rimuovere l'elemento `.joystick` e azzerare lo stato.
   - `legendaTasti(comandi, joystick = false)`: se `joystick`, push di `{ tasti: 'Trascina', etichetta: 'Joystick' }` prima delle righe Pausa/Riavvia.
