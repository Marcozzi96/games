# Snake Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Snake giocabile nel game shell: griglia 18×24, muri letali, +10/cibo, avvio pigro alla prima freccia.

**Architecture:** logica pura e testabile in `logica.ts` (stato immutabile, funzioni `creaStato`/`gira`/`tick` con RNG iniettato); `snake.ts` contiene solo il `Gioco`: loop a `setInterval` con intervallo decrescente, input da `ctx.comanda`, rendering su canvas scalato; `main.ts` registra il gioco.

**Tech Stack:** TypeScript strict (ES2022, ESM, alias `@/`), Vitest 5 + jsdom, Vite 8 (PWA). Niente nuove dipendenze.

**Spec:** `docs/superpowers/specs/2026-11-05-snake-design.md`

## Global Constraints

- Niente semicoloni; tipi con `import type`; funzioni senza ritorno significativo con `void` esplicito (convenzioni del progetto, AGENTS.md).
- Il gioco non tocca il DOM: solo `ctx.canvas` 2D in unità CSS (DPR già applicato dalla shell). Canvas di prova nei test: `canvas.width = 360; canvas.height = 480`.
- Comandi dichiarati dal gioco: esattamente `['su', 'giu', 'sx', 'dx']`. Mai `conferma` (P/Escape/R restano i soli tasti di flusso della shell).
- Valori fissati dalla spec: griglia 18×24; +10 punti per cibo; intervallo iniziale 140 ms; −5 ms per cibo; minimo 70 ms; muri e auto-collisione letali; coda comandi max 3.
- Record/punteggio/HUD/overlay/pausa: già della shell — il gioco solo chiama `ctx.invia.punteggio(v)` e `ctx.invia.fine(v)`.
- Beep del gioco: `import { beep } from '@/core/audio'` (cibo: `beep(880, 0.06)`). Game over: solo i beep della shell.
- Commit frequenti con messaggio in stile del repo (es. `feat: ...`, `test: ...`).

## Review Focus

Cose che la spec implica ma i test della logica pura non coprono direttamente — i test che le fissano sono aggiunti al task che possiede il codice:

- **Tick mentre la shell è in pausa** (P/Escape o auto-pausa su `visibilitychange`): il gioco non si muove e non finisce — fissato da un test di Task 2 (fake timers: `pausa()` poi `advanceTimersByTime` → `invia.fine` mai chiamata).
- **Teardown al ritorno al menù** (✕): nessun timer sopravvive, nessun comando smontato viene eseguito — fissato da un test di Task 2 (dopo `smonta()` + avvio, `advanceTimersByTime(5000)` → `fine` mai chiamata; `comanda` dopo `smonta()` è no-op).
- **Resize durante la partita**: il gioco non tocca `canvas.width/height` (la shell li possiede); la metrica `cella = min(larg/18, alt/24)` è ricalcolata a ogni disegno — fissato da un test di Task 2 (dopo aver ridimensionato il canvas, un disegno non lancia e il canvas resta intatto).
- **Doppia chiamata `reset()`** (overlay "Rigioca" + tasto R della shell possono sovrapporsi): la partita riparte pulita, un solo timer attivo — fissato da un test di Task 2.
- **Tastiera e pad touch insieme** (stesso comando da entrambi): il comportamento è identico perché entrambi passano per `ctx.comanda` — coperto implicitamente dalla stessa pipeline; nessun test dedicato.

```ts
import { describe, it, expect } from 'vitest'
import {
  COLONNE, RIGHE, PUNTI_PER_CIBO, INTERVALLO_INIZIALE, INTERVALLO_MINIMO,
  creaStato, gira, tick, ciboRandom,
} from '@/games/snake/logica'
import type { StatoSnake } from '@/games/snake/logica'

// RNG deterministico in [0,1): 0, 0.9, 0, 0.9, … (sequenza condivisa tra i
// test: ogni `creaStato`/`tick` che mangia consuma l'indice successivo).
const casualFissa = (() => {
  const valori = [0, 0.9]
  let i = 0
  return () => valori[i++ % valori.length]
})()

// Stato di prova: testa in (9,12) verso destra, corpo a sinistra, cibo a destra.
const statoBase = (): StatoSnake => ({
  serpente: [{ x: 9, y: 12 }, { x: 8, y: 12 }, { x: 7, y: 12 }],
  direzione: 'dx',
  coda: [],
  cibo: { x: 15, y: 12 },
  punti: 0,
  intervallo: INTERVALLO_INIZIALE,
  finita: false,
})

describe('creaStato', () => {
  it('parte con 3 celle al centro, direzione dx, 0 punti, 140 ms', () => {
    const s = creaStato(casualFissa)
    expect(s.serpente).toEqual([{ x: 9, y: 12 }, { x: 8, y: 12 }, { x: 7, y: 12 }])
    expect(s.direzione).toBe('dx')
    expect(s.coda).toEqual([])
    expect(s.punti).toBe(0)
    expect(s.intervallo).toBe(140)
    expect(s.finita).toBe(false)
  })

  it('posa il cibo su una cella libera usando l\'RNG fornito (0.9 → (11,21))', () => {
    // 2ª chiamata → 0.9; 429 libere: floor(0.9*429)=386 → 387ª libera = 389
    // (saltate le 3 occupate 223-225) → (11,21)
    const s = creaStato(casualFissa)
    expect(s.cibo).toEqual({ x: 11, y: 21 })
    expect(s.serpente.some((c) => c.x === 11 && c.y === 21)).toBe(false)
  })
})

describe('gira', () => {
  it('accoda una direzione valida (max 3, niente duplicati consecutivi)', () => {
    const s = gira(gira(gira(statoBase(), 'su'), 'sx'), 'giu')
    expect(s.coda).toEqual(['su', 'sx', 'giu'])
    expect(gira(s, 'dx').coda).toEqual(['su', 'sx', 'giu']) // coda piena: scartato
  })

  it('scarta l\'opposta della direzione effettiva (ultima in coda o corrente)', () => {
    const s = gira(statoBase(), 'su')
    expect(gira(s, 'giu').coda).toEqual(['su']) // opposta di 'su' in coda
    const d = gira(statoBase(), 'dx')
    expect(d.coda).toEqual([]) // 'dx' è già la direzione corrente
  })

  it('ignora i comandi non direzionali', () => {
    expect(gira(statoBase(), 'conferma').coda).toEqual([])
    expect(gira(statoBase(), 'punta' as StatoSnake['direzione']).coda).toEqual([])
  })

  it('non cambia la direzione corrente: cambia solo al tick', () => {
    expect(gira(statoBase(), 'su').direzione).toBe('dx')
  })
})

describe('tick', () => {
  it('avanza la testa nella direzione corrente', () => {
    const s = tick(statoBase())
    expect(s.serpente[0]).toEqual({ x: 10, y: 12 })
    expect(s.serpente).toHaveLength(3)
  })

  it('applica la coda: ogni tick consuma un comando', () => {
    const s = tick(gira(statoBase(), 'su'))
    expect(s.direzione).toBe('su')
    expect(s.serpente[0]).toEqual({ x: 9, y: 11 })
  })

  it('muro: testa fuori griglia → finita, serpente immobile', () => {
    const s = tick({ ...statoBase(), serpente: [{ x: COLONNE - 1, y: 0 }, { x: COLONNE - 2, y: 0 }] })
    expect(s.finita).toBe(true)
    expect(s.serpente[0]).toEqual({ x: COLONNE - 1, y: 0 })
    expect(tick(s).serpente[0]).toEqual({ x: COLONNE - 1, y: 0 }) // tick dopo la fine: no-op
  })

  it('auto-collisione: testa su una cella del corpo → finita', () => {
    // A U: la testa in (5,5) va in (4,5), occupata dal corpo (non la coda (4,6))
    const s = tick({
      ...statoBase(),
      serpente: [
        { x: 5, y: 5 }, { x: 6, y: 5 }, { x: 6, y: 4 }, { x: 5, y: 4 },
        { x: 4, y: 4 }, { x: 4, y: 5 }, { x: 4, y: 6 },
      ],
      direzione: 'sx',
    })
    expect(s.finita).toBe(true)
  })

  it('cibo: cresce di 1, +10 punti, intervallo −5 ms, nuovo cibo dall\'RNG (0 → (0,0))', () => {
    // cibo sotto il prossimo passo della testa; 3ª chiamata RNG → 0
    const s = tick({ ...statoBase(), cibo: { x: 10, y: 12 } })
    expect(s.serpente).toHaveLength(4)
    expect(s.punti).toBe(PUNTI_PER_CIBO)
    expect(s.intervallo).toBe(135)
    expect(s.cibo).toEqual({ x: 0, y: 0 })
  })

  it('intervallo mai sotto il minimo', () => {
    let s: StatoSnake = { ...statoBase(), intervallo: INTERVALLO_MINIMO, cibo: { x: 10, y: 12 } }
    s = tick(s)
    expect(s.intervallo).toBe(INTERVALLO_MINIMO)
  })

  it('soda: il cibo non spawn mai sulla serpente (RNG dedicato 0.9 → (11,21))', () => {
    // RNG dedicato (non la sequenza condivisa): 428 libere dopo il pasto,
    // floor(0.9*428)=385 → 386ª libera = 389 (saltate le 4 occupate 223-226)
    // → (11,21), non occupato dalla serpente.
    const s = tick({ ...statoBase(), cibo: { x: 10, y: 12 } }, () => 0.9)
    expect(s.cibo).toEqual({ x: 11, y: 21 })
    expect(s.serpente.some((c) => c.x === 11 && c.y === 21)).toBe(false)
  })

  it('griglia piena → finita senza cercare cibo (vittoria)', () => {
    // 431 celle: l'unica libera (10,12) è il cibo; la testa ci arriva, mangia
    // e completa la griglia → vittoria, senza chiamare ciboRandom.
    const celle: StatoSnake['serpente'] = [{ x: 9, y: 12 }]
    for (let y = 0; y < RIGHE; y++) for (let x = 0; x < COLONNE; x++) {
      if (x === 10 && y === 12) continue
      celle.push({ x, y })
    }
    const piena = { ...statoBase(), serpente: celle, cibo: { x: 10, y: 12 } }
    const s = tick(piena)
    expect(s.finita).toBe(true)
    expect(s.serpente).toHaveLength(COLONNE * RIGHE)
  })
})

describe('ciboRandom', () => {
  it('usa l\'RNG per scegliere tra le celle libere (0.9, 429 libere) → (11,21)', () => {
    // floor(0.9*429)=386 → 387ª libera = 389 (saltate le 3 occupate 223-225)
    expect(ciboRandom(statoBase(), () => 0.9)).toEqual({ x: 11, y: 21 })
  })
})
```

Nota per chi implementa: `casualFissa` è condivisa tra gli `it` (ordine di esecuzione Vitest: top-to-bottom) e i valori attesi sono calcolati su quella sequenza [0, 0.9, 0, 0.9, …]: 1° `creaStato`→0, 2°→0.9, 1° `tick` che mangia→0, 2°→0.9. I test che devono fissare un valore specifico (0.9) usano un RNG dedicato `() => 0.9` per non dipendere dalla posizione. Se un valore atteso non torna, verifica la sequenza di consumo e correggi l'attesa, non la logica.

- [ ] **Step 3: Implementa `src/games/snake/logica.ts`**

Firme come nell'Interfaces block. Note di implementazione:

- `casual = Math.random` per default (parametro opzionale).
- `creaStato`: serpente centrata `{9,12},{8,12},{7,12}`, direzione `'dx'`, poi `cibo: ciboRandom(stato, casual)`.
- `ciboRandom`: indici liberi `0..COLONNE*RIGHE-1` esclusi quelli occupati; `i = libero[floor(casual() * libero.length)]`; ritorna `{x: i % COLONNE, y: floor(i / COLONNE)}`. Se `libero` è vuoto ritorna il vecchio `stato.cibo` (già gestito da `tick`).
- `gira`: se il comando non è in `{su, giu, sx, dx}` ritorna `stato` invariato; direzione effettiva = `coda.length ? coda[coda.length-1] : direzione`; se comando === effettiva o comando è l'opposta dell'effettiva ritorna `stato`; se `coda.length >= CODA_MAX` ritorna `stato`; altrimenti nuovo stato con `coda` allungata (copia dell'array).
- `tick`: se `finita` ritorna `stato`; nuova direzione = primo elemento di `coda` (se presente); `testa = serpente[0] + DELTA[direzione]`; fuori da `0..COLONNE-1 / 0..RIGHE-1` → `{...stato, finita: true}`; auto-collisione se `testa` ∈ `serpente` esclusa l'ultima cella (la coda si ritrae, salvo che mangia); se mangia: `punti + PUNTI_PER_CIBO`, `intervallo = max(INTERVALLO_MINIMO, intervallo - ACCELERAZIONE)`, nuovo corpo con testa in testa e tutta la coda vecchia, `cibo: griglia piena ? vecchio cibo : ciboRandom(...)` e se piena anche `finita: true`; altrimenti corpo = `[testa, ...serpente.slice(0, -1)]`.
- Stile: nessun semicolone, `void` non serve (tutte le funzioni ritornano), tipi con `import type { Comando }`.

```ts
import { describe, it, expect, vi, beforeEach, afterEach } from 'vitest'
import { snake } from '@/games/snake/snake'
import type { Comando, HandleGioco } from '@/core/types'

type CtxFinto = {
  canvas: HTMLCanvasElement
  invia: { punteggio: (v: number) => void; fine: (v: number) => void }
  comanda: (fn: (c: Comando | [Comando, number, number]) => void) => void
  handle: HandleGioco
}

function ctxFinto(): { ctx: CtxFinto; comanda: (c: string) => void } {
  const canvas = document.createElement('canvas')
  canvas.width = 360
  canvas.height = 480
  const listeners: Array<(c: Comando | [Comando, number, number]) => void> = []
  const invia = { punteggio: vi.fn(), fine: vi.fn() }
  const handle = snake.crea({ canvas, invia, comanda: (fn) => listeners.push(fn) })
  const ctx: CtxFinto = { canvas, invia, comanda: (fn) => listeners.push(fn), handle }
  return { ctx, comanda: (c) => listeners.forEach((fn) => fn(c as Comando)) }
}

describe('snake (Gioco)', () => {
  beforeEach(() => vi.useFakeTimers())
  afterEach(() => vi.useRealTimers())

  it('è registrato col contratto atteso', () => {
    expect(snake.id).toBe('snake')
    expect(snake.nome).toBe('Snake')
    expect(snake.icona).toBe('/icons/icon-snake.svg')
    expect(snake.comandi).toEqual(['su', 'giu', 'sx', 'dx'])
  })

  it('avvio pigro: niente tick prima della prima freccia', () => {
    const { ctx, comanda } = ctxFinto()
    vi.advanceTimersByTime(10_000)
    expect(ctx.invia.fine).not.toHaveBeenCalled()
    comanda('su') // avvia: un passo, poi timer
    expect(ctx.invia.fine).not.toHaveBeenCalled()
  })

  it('dopo la prima freccia il loop corre: sbatte sul muro e invia.fine(0)', () => {
    const { ctx, comanda } = ctxFinto()
    comanda('su') // passo 1: testa in (9,11); il timer parte a 140 ms
    // 12 tick di intervallo portano la testa a (9,0) e poi fuori → fine
    vi.advanceTimersByTime(12 * 140)
    expect(ctx.invia.fine).toHaveBeenCalledTimes(1)
    expect(ctx.invia.fine).toHaveBeenCalledWith(0)
  })

  it('pausa: nessun tick finché non si riprende (Review Focus)', () => {
    const { ctx, comanda } = ctxFinto()
    comanda('su')
    vi.advanceTimersByTime(140 * 5) // testa in (9,6)
    ctx.handle.pausa()
    vi.advanceTimersByTime(60_000)
    expect(ctx.invia.fine).not.toHaveBeenCalled()
    ctx.handle.riprendi()
    vi.advanceTimersByTime(140 * 10) // dal (9,6): 7 tick al muro
    expect(ctx.invia.fine).toHaveBeenCalledTimes(1)
  })

  it('smonta: nessun tick né comandi dopo il teardown (Review Focus)', () => {
    const { ctx, comanda } = ctxFinto()
    comanda('su')
    ctx.handle.smonta()
    vi.advanceTimersByTime(60_000)
    expect(ctx.invia.fine).not.toHaveBeenCalled()
    comanda('giu') // listener smontato: no-op
    expect(ctx.invia.fine).not.toHaveBeenCalled()
  })

  it('reset: riparte in attesa, doppio reset sicuro (Review Focus)', () => {
    const { ctx, comanda } = ctxFinto()
    comanda('su')
    vi.advanceTimersByTime(12 * 140)
    expect(ctx.invia.fine).toHaveBeenCalledTimes(1)
    ctx.handle.reset()
    ctx.handle.reset() // doppio: deve restare un solo stato pulito
    vi.advanceTimersByTime(10_000) // ancora in attesa: nessun tick
    expect(ctx.invia.fine).toHaveBeenCalledTimes(1)
    comanda('su')
    vi.advanceTimersByTime(12 * 140) // di nuovo 12 tick al muro
    expect(ctx.invia.fine).toHaveBeenCalledTimes(2)
    expect(ctx.invia.fine).toHaveBeenLastCalledWith(0)
  })

  it('resize: il gioco non modifica canvas.width/height (Review Focus)', () => {
    const { ctx, comanda } = ctxFinto()
    comanda('su')
    vi.advanceTimersByTime(140) // un tick → un tentativo di disegno
    ctx.canvas.width = 300
    ctx.canvas.height = 400
    vi.advanceTimersByTime(140)
    expect(ctx.canvas.width).toBe(300)
    expect(ctx.canvas.height).toBe(400)
    expect(ctx.invia.fine).not.toHaveBeenCalled()
  })
})
```

Struttura (l'implementatore scrive il corpo; qui i vincoli fissi):

- Stato interno a `crea`: `stato: StatoSnake`, `avviata: boolean`, `pauSata: boolean`, `smontata: boolean`, `timer: number | undefined` (da `window.setInterval`).
- Il callback `onComando` registrato con `ctx.comanda` deve fare da solo i controlli `smontata || pauSata` (no-op) — la shell li fa già, ma i test usano una fake che inoltra sempre (cfr. test `smonta`).
- Pipeline comandi: se `!avviata` → `avviata = true`, `gira`, `tick`, disegno, avvio timer; se `finita` → no-op; altrimenti `gira` + disegno (il tick avviene sul timer).
- Timer: `timer = window.setInterval(() => { stato = tick(stato); disegna(); if (stato.finita) { stopTimer(); ctx.invia.fine(stato.punti) } }, stato.intervallo)`. Quando `intervallo` cambia (cibo) si rigenera il timer con il nuovo valore.
- Beep cibo: nel disegno (o nel tick wrapper) se i punti sono cresciuti dal disegno precedente → `beep(880, 0.06)`.
- Rendering: `c = ctx.canvas.getContext('2d'); if (!c) return` (jsdom: no-op silenzioso, come in `tests/smoke/finto.ts`). La shell ha applicato `setTransform(dpr,0,0,dpr,0,0)`, quindi le coordinate di disegno sono in unità CSS: `larg = ctx.canvas.clientWidth || ctx.canvas.width`, `alt = ctx.canvas.clientHeight || ctx.canvas.height` (i fallback servono solo a jsdom, dove si è già tornati). `cella = Math.min(larg / COLONNE, alt / RIGHE)`; offset di centratura `offX = (larg - cella*COLONNE)/2`, `offY = (alt - cella*RIGHE)/2`; sfondo `#0f172a`, griglia `rgba(148,163,184,0.08)`, corpo `#22c55e`, testa `#4ade80`, cibo `#f87171` (cerchio). Se `!avviata`: testo centrato `Premi una freccia per iniziare` (font `16px system-ui`, colore `#94a3b8`).
- `pausa()`: `pauSata = true`, stop timer. `riprendi()`: `pauSata = false`, se `avviata && !finita` riavvia il timer. `reset()`: stop timer, `stato = creaStato()`, `avviata = false`, `punti HUD` via `ctx.invia.punteggio(0)`, disegno. `smonta()`: `smontata = true`, stop timer.
- `export const snake: Gioco = { id: 'snake', nome: 'Snake', icona: '/icons/icon-snake.svg', comandi: ['su', 'giu', 'sx', 'dx'], crea }`.

## Note per chi esegue

- Se un valore atteso nei test della logica non torna, la causa è quasi sempre la sequenza dell'RNG fissa (0, 0.9, 0, 0.9…): verifica quale indice consuma ciascuna chiamata (quanti `ciboRandom` l'hanno preceduti) e correggi l'attesa — la logica è fissata dal design doc.
- Il canvas di jsdom non ha un 2d context: i test del Task 2 verificano flusso/timer, non pixel. Il rendering vero si verifica con `npm run dev` (apri il menù → Snake).
- Non aggiungere comandi `conferma`/`ruota`: la spec lo esclude esplicitamente.
