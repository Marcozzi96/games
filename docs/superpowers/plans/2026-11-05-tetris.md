# Tetris Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tetris classico-moderno giocabile nel game shell: griglia 10×20, 7-bag, ghost, next (1), hard drop, wall-kick semplice.

**Architecture:** logica pura e testabile in `logica.ts` (stato immutabile, bag, collisioni, rotazione con kick, scoring); `tetris.ts` contiene solo il `Gioco`: loop a `setInterval` (gravità), timer soft-drop, input da `ctx.comanda`, rendering su canvas con area next; `main.ts` registra il gioco.

**Tech Stack:** TypeScript strict (ES2022, ESM, alias `@/`), Vitest 5 + jsdom, Vite 8 (PWA). Niente nuove dipendenze.

**Spec:** `docs/superpowers/specs/2026-11-05-tetris-design.md`

## Global Constraints

- Niente semicoloni; tipi con `import type`; funzioni senza ritorno significativo con `void` esplicito (convenzioni del progetto, AGENTS.md).
- Il gioco non tocca il DOM: solo `ctx.canvas` 2D in unità CSS (DPR già applicato dalla shell). Canvas di prova nei test: `canvas.width = 360; canvas.height = 480`.
- Comandi dichiarati dal gioco: esattamente `['sx', 'dx', 'giu', 'ruota', 'conferma']` (ordine: i 4 direzionali prima, poi conferma e ruota — il pad della shell li disegna in quest'ordine).
- Valori fissati dalla spec: griglia 10×20; 7-bag; wall-kick con offset `[0, -1, 1, -2, 2]`; gravità 800 ms − 70 ms/livello, min 100 ms; +1 livello ogni 10 linee; punti linee 100/300/500/800 × livello; soft drop +1/cella (finestra 150 ms a 50 ms); hard drop +2/cella; no hold, no lock delay.
- Record/punteggio/HUD/overlay/pausa: già della shell — il gioco solo chiama `ctx.invia.punteggio(v)` e `ctx.invia.fine(v)`.
- Beep del gioco: `import { beep } from '@/core/audio'`; solo `beep(freq, durata)` (default square). Game over: solo i beep della shell.
- Il gioco non modifica file fuori dalla sua cartella + `src/main.ts` (registrazione) + `public/icons/` (icona): zero modifiche a `core/` e `app/` (anti-goal spec shell).
- Commit frequenti con messaggio in stile del repo (es. `feat: ...`).

  ```ts
  export type IdTessera = 'I' | 'O' | 'T' | 'S' | 'Z' | 'J' | 'L'
  export type Forma = number[][]            // righe di 0/1, forma corrente
  export type Tessera = { id: IdTessera; forma: Forma; x: number; y: number }
  export type StatoTetris = {
    griglia: string[]                       // COLONNE*RIGHE; 'libero' | IdTessera; idx = y*COLONNE+x
    tessera: Tessera | null                 // null = in attesa del primo input
    bag: IdTessera[]                        // pezzi in attesa; bag[0] = prossimo (anteprima)
    punti: number
    linee: number
    livello: number
    fine: boolean
  }
  ```

  Costanti esportate:
  - `const COLONNE = 10`, `const RIGHE = 20`
  - `const INTERVALLO_INIZIALE = 800`, `const RALLENTAMENTO_PER_LIVELLO = 70`, `const INTERVALLO_MINIMO = 100`
  - `const LINEE_PER_LIVELLO = 10`, `const PUNTI_LINIE = [0, 100, 300, 500, 800]`
  - `const PUNTI_SOFT_DROP = 1`, `const PUNTI_HARD_DROP = 2`
  - `const SOFT_DROP_MS = 150`, `const INTERVALLO_SOFT_DROP = 50`
  - `const COLORE_TESSERA: Record<IdTessera, string>` (valori nel passo 3)
  - `const FORME: Record<IdTessera, Forma>` (forme di spawn, passo 3)

  Funzioni (tutte pure, `casual` opzionale con default `Math.random`):

  - `function avvia(stato: StatoTetris, casual?: () => number): StatoTetris`

```ts
import { describe, it, expect } from 'vitest'
import {
  COLONNE, RIGHE, PUNTI_LINIE, PUNTI_SOFT_DROP, PUNTI_HARD_DROP,
  FORME,
  creaStato, avvia, muovi, ruota, softDrop, hardDrop, tick, ghost,
  intervalloGravita, mescolaBag,
} from '@/games/tetris/logica'
import type { StatoTetris, IdTessera } from '@/games/tetris/logica'

const grigliaVuota = (): string[] => Array(COLONNE * RIGHE).fill('libero')

// Stato di prova: tessera T in cima al centro (x=3, y=0), griglia vuota.
const statoT = (): StatoTetris => ({
  griglia: grigliaVuota(),
  tessera: { id: 'T', forma: FORME.T, x: 3, y: 0 },
  bag: ['I'],
  punti: 0,
  linee: 0,
  livello: 1,
  fine: false,
})

describe('creaStato / mescolaBag', () => {
  it('parte in attesa: tessera null, griglia vuota, bag di 7, livello 1', () => {
    const s = creaStato(() => 0)
    expect(s.tessera).toBeNull()
    expect(s.griglia).toEqual(grigliaVuota())
    expect(s.bag).toHaveLength(7)
    expect(s.punti).toBe(0)
    expect(s.linee).toBe(0)
    expect(s.livello).toBe(1)
    expect(s.fine).toBe(false)
  })

  it('mescolaBag: permutazione delle 7 tessere (Fisher-Yates)', () => {
    const b = mescolaBag(() => 0) // solo scambi a indice 0: invariata
    expect(b).toEqual(['I', 'O', 'T', 'S', 'Z', 'J', 'L'])
    const b2 = mescolaBag(() => 1) // (i-1)/i → 0: scambio identico, invariata
    expect(b2).toEqual(['I', 'O', 'T', 'S', 'Z', 'J', 'L'])
    const tutte = mescolaBag(() => 0.5)
    expect([...tutte].sort()).toEqual(['I', 'J', 'L', 'O', 'S', 'T', 'Z'])
  })

  it('bag di creaStato usa il RNG iniettato (stessa sequenza di mescolaBag)', () => {
    const s = creaStato(() => 0.5)
    expect(s.bag).toEqual(mescolaBag(() => 0.5))
  })
})

describe('avvia', () => {
  it('spawna bag[0] al centro in cima e lo toglie dal bag', () => {
    // bag[0] = 'T': forma 2×3 → x = floor((10-3)/2) = 3, y = 0
    const s = avvia({ ...statoT(), tessera: null, bag: ['T', 'I'] })
    expect(s.tessera).toEqual({ id: 'T', forma: FORME.T, x: 3, y: 0 })
    expect(s.bag).toEqual(['I'])
  })

  it('I spawna a x=3 (larghezza 4), O a x=4 (larghezza 2)', () => {
    const i = avvia({ ...statoT(), tessera: null, bag: ['I'] })
    expect(i.tessera?.x).toBe(3)
    const o = avvia({ ...statoT(), tessera: null, bag: ['O'] })
    expect(o.tessera?.x).toBe(4)
  })

  it('bag vuota: se ne genera una nuova mescolata dal RNG', () => {
    const s = avvia({ ...statoT(), tessera: null, bag: [] }, () => 0.5)
    expect(s.bag).toEqual(mescolaBag(() => 0.5).slice(1))
    expect(s.tessera?.id).toBe(mescolaBag(() => 0.5)[0])
  })

  it('se c\'è già una tessera attiva: no-op', () => {
    const s = statoT()
    expect(avvia(s)).toBe(s)
  })

  it('block out: spawn in collisione → fine (tessera non spawnata)', () => {
    const g = grigliaVuota()
    for (let x = 0; x < COLONNE; x++) { g[x] = 'J'; g[10 + x] = 'J' } // righe 0-1 piene
    const s = avvia({ ...statoT(), griglia: g, tessera: null, bag: ['T'] })
    expect(s.fine).toBe(true)
    expect(s.tessera).toBeNull()
  })
})

describe('muovi', () => {
  it('sposta di 1 cella se libero', () => {
    const s = muovi(statoT(), 1)
    expect(s.tessera?.x).toBe(4)
    expect(muovi(s, -1).tessera?.x).toBe(3)
  })

  it('muro: non esce dalla griglia', () => {
    let s = statoT()
    for (let i = 0; i < 4; i++) s = muovi(s, -1) // x: 3 → -1 (bloccato a 0)
    expect(s.tessera?.x).toBe(0)
  })

  it('tessera null o fine: no-op', () => {
    const vuoto = { ...statoT(), tessera: null }
    expect(muovi(vuoto, 1).tessera).toBeNull()
    const finita = { ...statoT(), fine: true }
    expect(muovi(finita, 1).tessera?.x).toBe(3)
  })
})

describe('ruota', () => {
  it('ruota 90° oraria la forma (T: 2×3 → 3×2)', () => {
    const s = ruota(statoT())
    expect(s.tessera?.forma).toEqual([[0, 1], [1, 1], [0, 1]])
    expect(s.tessera?.x).toBe(3) // senza kick
    expect(s.tessera?.y).toBe(0)
  })

  it('quattro rotazioni = forma originale', () => {
    let s = statoT()
    for (let i = 0; i < 4; i++) s = ruota(s)
    expect(s.tessera?.forma).toEqual(FORME.T)
  })

  it('O: rotazione no-op (stessa forma, stessa posizione)', () => {
    const s = { ...statoT(), tessera: { id: 'O' as IdTessera, forma: FORME.O, x: 4, y: 0 } }
    expect(ruota(s).tessera).toEqual(s.tessera)
  })

  it('wall-kick: contro il muro sinistro scatta l\'offset -1', () => {
    let s = { ...statoT(), tessera: { id: 'T' as IdTessera, forma: [[0, 1, 0], [1, 1, 1]], x: -1, y: 5 } }
    // forma 2×3 a x=-1: colonna -1 occupata → fuori. Rotazione in 3×2 a x=-1
    // occuperebbe ancora la colonna -1 (colonna 1 della nuova forma piena) → kick.
    s = ruota(s)
    expect(s.tessera?.x).toBe(0)
  })

  it('niente kick disponibile: rotazione rifiutata (stato invariato)', () => {
    // T orizzontale (3×2) incastrata in una fossa larga 3 sul bordo:
    // righe 18-19, x=0..2; la rotazione in 2×3 non trova spazio nemmeno kickando.
    const g = grigliaVuota()
    for (let y = 17; y < RIGHE; y++) {
      g[y * COLONNE + 3] = 'J' // parete a destra della fossa
    }
    const s = {
      ...statoT(),
      griglia: g,
      tessera: { id: 'T' as IdTessera, forma: [[1, 1, 0], [0, 1, 1]], x: 0, y: 17 },
    }
    expect(ruota(s)).toBe(s)
  })
})

describe('softDrop / tick / ghost', () => {
  it('softDrop: scende di 1, +1 punto', () => {
    const s = softDrop(statoT())
    expect(s.tessera?.y).toBe(1)
    expect(s.punti).toBe(PUNTI_SOFT_DROP)
  })

  it('softDrop a terra: non scende, nessun punto (torna al tick)', () => {
    const s = softDrop({ ...statoT(), tessera: { ...statoT().tessera!, y: RIGHE - 2 } })
    expect(s.tessera?.y).toBe(RIGHE - 2)
    expect(s.punti).toBe(0)
  })

  it('tick: scende di 1, nessun punto', () => {
    const s = tick(statoT())
    expect(s.tessera?.y).toBe(1)
    expect(s.punti).toBe(0)
  })

  it('ghost: profondità fino alla collisione', () => {
    expect(ghost(statoT())).toBe(18) // T (altezza 2) da y=0 fino a y=18
    const piena = grigliaVuota()
    for (let x = 0; x < COLONNE; x++) piena[18 * COLONNE + x] = 'J'
    expect(ghost({ ...statoT(), griglia: piena })).toBe(16)
  })

  it('tick a terra: lock + linee + bag', () => {
    // T a y=18 (a terra su griglia vuota): il tick la locka.
    const s = tick({ ...statoT(), tessera: { ...statoT().tessera!, y: 18 } })
    expect(s.tessera?.id).toBe('I') // spawnata bag[0]
    expect(s.bag).toEqual([])
    expect(s.griglia[19 * COLONNE + 4]).toBe('T') // cella (4,19)
  })

  it('lock sulla riga 20: le linee si puliscono prima del block out', () => {
    // Righe 0-17 piene di J tranne la colonna 3; riga 18 piena di J tranne la
    // colonna 4; riga 19 vuota. T (2×3) a x=3, y=17: celle (4,17), (3,18), (4,18).
    // Il tick la locka: le righe 18-19 si completano e si puliscono; le J
    // delle righe 0-17 scendono di 2.
    const g = grigliaVuota()
    for (let y = 0; y < 18; y++) for (let x = 0; x < COLONNE; x++) if (x !== 3) g[y * COLONNE + x] = 'J'
    for (let x = 0; x < COLONNE; x++) if (x !== 4) g[18 * COLONNE + x] = 'J'
    const s = tick({ ...statoT(), griglia: g, tessera: { id: 'T', forma: FORME.T, x: 3, y: 17 }, bag: ['I', 'O'] })
    expect(s.linee).toBe(2)
    expect(s.livello).toBe(1)
    expect(s.fine).toBe(false)
    expect(s.griglia[19 * COLONNE + 4]).toBe('J') // (4,18) → scivolata in (4,19)
    expect(s.griglia[18 * COLONNE + 3]).toBe('J') // colonna 3: J scivolata da (17,3)
    expect(s.tessera?.id).toBe('I') // spawn in cima dopo il clear
  })

  it('punti linee: 1/2/3/4 linee = 100/300/500/800 × livello', () => {
    const statoBase = (): StatoTetris => ({ ...statoT(), bag: ['I', 'O', 'T'] })
    for (const n of [1, 2, 3, 4] as const) {
      const s = lockConLinee(n, statoBase())
      expect(s.punti).toBe(PUNTI_LINIE[n])
    }
    // livello 2: tutto × 2
    const s = lockConLinee(4, { ...statoT(), livello: 2, bag: ['I', 'O', 'T'] })
    expect(s.punti).toBe(PUNTI_LINIE[4] * 2)
  })

  it('livello sale ogni 10 linee e cambia l\'intervallo', () => {
    expect(intervalloGravita(1)).toBe(800)
    expect(intervalloGravita(2)).toBe(730)
    expect(intervalloGravita(11)).toBe(100) // floor: 800-700=100
    expect(intervalloGravita(12)).toBe(100) // mai sotto il minimo
    // 9 linee + 4 in un colpo = 13 → livello 2
    const s = lockConLinee(4, { ...statoT(), linee: 9, bag: ['I', 'O', 'T'] })
    expect(s.livello).toBe(2)
  })
})

describe('hardDrop', () => {
  it('cade fino al ghost, +2/cella, lock immediato', () => {
    const s = hardDrop(statoT()) // ghost = 18 → 18 celle × 2 = 36
    expect(s.punti).toBe(18 * PUNTI_HARD_DROP)
    expect(s.tessera?.id).toBe('I') // spawnata dal bag
    expect(s.griglia[19 * COLONNE + 4]).toBe('T')
  })

  it('a terra: 0 punti, lock immediato', () => {
    const s = hardDrop({ ...statoT(), tessera: { ...statoT().tessera!, y: 18 } })
    expect(s.punti).toBe(0)
    expect(s.tessera?.id).toBe('I')
  })

  it('tessera null: no-op', () => {
    const vuoto = { ...statoT(), tessera: null }
    expect(hardDrop(vuoto).tessera).toBeNull()
  })
})

// Helper di test: completa `n` righe piene (in cima) con la tessera I
// verticale e locka, senza altre distrazioni.
function lockConLinee(n: 1 | 2 | 3 | 4, base: StatoTetris): StatoTetris {
  const g = grigliaVuota()
  for (let y = 0; y < n; y++) for (let x = 0; x < COLONNE; x++) if (x !== 4) g[y * COLONNE + x] = 'J'
  // I verticale (forma 4×1 → ruotata in 1×4) in colonna 4, in cima:
  const iVert: StatoTetris = {
    ...base,
    griglia: g,
    tessera: { id: 'I', forma: [[1], [1], [1], [1]], x: 4, y: 0 },
  }
  return hardDrop(iVert)
}
```

export const COLORE_TESSERA: Record<IdTessera, string> = {

- `ruotaMatrice(f: Forma): Forma` (non esportato): 90° oraria, `rot[j][ri - 1 - i] = f[i][j]`
  con `ri` = numero di righe, `rc` = numero di colonne.
- `collisione(griglia, forma, x, y): boolean` (non esportato): per ogni cella piena
  `gx = x + j`, `gy = y + i` → `gx < 0 || gx >= COLONNE || gy >= RIGHE || griglia[gy*COLONNE+gx] !== 'libero'`
  → true. `gy < 0` non può capitare con le forme di spawn a `y >= 0`; trattalo comunque come collisione.
- `mescolaBag`: copia di `['I','O','T','S','Z','J','L']`, Fisher-Yates
  `for (let i = n-1; i > 0; i--) { const j = floor(casual() * (i+1)); swap }`.
  Con `casual() === 0` o `1` tutti gli indici `j` sono 0 → permutazione identica (è ciò che fissa i test).
- `creaStato`: `griglia` vuota, `tessera: null`, `bag: mescolaBag(casual)`, punti/linee 0, livello 1, fine false.
- `avvia`: se `tessera !== null` o `fine` → stato. `bag = bag.length ? bag : mescolaBag(casual)`;
  `id = bag[0]`; forma `FORME[id]`; `x = floor((COLONNE - larghezza) / 2)`, `y = 0`;
  se `collisione` → `{ ...stato, bag: bag.slice(1), fine: true }` (tessera resta null);
  altrimenti `{ ...stato, bag: bag.slice(1), tessera: { id, forma, x, y } }`.
- `muovi`: se `!tessera || fine` → stato; se `collisione(x+dx)` → stato; altrimenti nuovo stato con `x+dx`.
- `ruota`: se `!tessera || fine` → stato; `nf = ruotaMatrice(forma)`; per `off` in `[0, -1, 1, -2, 2]`:
  se `!collisione(x+off, y)` → nuovo stato con `{ id, forma: nf, x: x+off, y }`; altrimenti stato.
- `softDrop`: se `!tessera || fine` → stato; se `!collisione(y+1)` → `{ ...stato, tessera: {...tessera, y+1}, punti + PUNTI_SOFT_DROP }`; altrimenti stato.
- `tick`: se `!tessera || fine` → stato; se `!collisione(y+1)` → scende di 1 (senza punti);
  altrimenti `lock` (sotto).
- `hardDrop`: se `!tessera || fine` → stato; `d = ghost(stato)`; `punti + d * PUNTI_HARD_DROP`;
  `lock` con la tessera a `y + d`.
- `lock(stato, tessera)` (non esportato): 1) copia la griglia, scrivi `id` nelle celle della tessera;
  2) rimuovi le righe piene; 3) `n` = righe rimosse; `punti + PUNTI_LINIE[n] * livello` (il livello
  CORRENTE, prima del ricalcolo); poi `linee + n` e `livello = floor(linee / LINEE_PER_LIVELLO) + 1`;
  4) `bag = bag.length ? bag : mescolaBag()`; spawna `bag[0]` (stessa formula di `avvia`);
  5) se lo spawn collide → `tessera: null, fine: true`; altrimenti nuova tessera.
- `ghost`: se `!tessera` → 0; conta i `y` incrementabili finché `!collisione`.
- `intervalloGravita(livello) = max(INTERVALLO_MINIMO, INTERVALLO_INIZIALE - (livello - 1) * RALLENTAMENTO_PER_LIVELLO)`.
- Stile: nessun semicolone, tutte le funzioni ritornano uno stato (niente `void`), niente `import` da `@/core/types`.

import { tetris } from '@/games/tetris/tetris'
import type { Comando, HandleGioco } from '@/core/types'

type CtxFinto = {
  canvas: HTMLCanvasElement
  invia: { punteggio: (v: number) => void; fine: (v: number) => void }
  comanda: (fn: (c: Comando | [Comando, number, number]) => void) => void
  handle: HandleGioco
}

function ctxFinto(): { ctx: CtxFinto; comanda: (c: string) => void } {
  const canvas = document.createElement('canvas')
  canvas.width = 360
  canvas.height = 480
  const listeners: Array<(c: Comando | [Comando, number, number]) => void> = []
  const invia = { punteggio: vi.fn(), fine: vi.fn() }
  const handle = tetris.crea({ canvas, invia, comanda: (fn) => listeners.push(fn) })
  const ctx: CtxFinto = { canvas, invia, comanda: (fn) => listeners.push(fn), handle }
  return { ctx, comanda: (c) => listeners.forEach((fn) => fn(c as Comando)) }
}

    vi.useFakeTimers()
    vi.spyOn(Math, 'random').mockReturnValue(0) // bag deterministica: I, O, T, …
  })

    vi.useRealTimers()
    vi.restoreAllMocks()
  })

  it('è registrato col contratto atteso', () => {
    expect(tetris.id).toBe('tetris')
    expect(tetris.nome).toBe('Tetris')
    expect(tetris.icona).toBe('/icons/icon-tetris.svg')
    expect(tetris.comandi).toEqual(['sx', 'dx', 'giu', 'ruota', 'conferma'])
  })

  it('avvio pigro: niente tick prima del primo comando', () => {
    const { ctx } = ctxFinto()
    vi.advanceTimersByTime(60_000)
    expect(ctx.invia.fine).not.toHaveBeenCalled()
  })

  it('il primo comando spawna e avvia: 19 tick di gravità portano alla fine', () => {
    // bag[0] = I orizzontale (1×4) a y=0: 19 passi fino alla riga 19; al tick
    // 19 locka (senza linee) e spawna O. Dopo 19 tick NON è finita; dopo 38

    expect(ctx.invia.fine).not.toHaveBeenCalled()

    expect(ctx.invia.punteggio).toHaveBeenCalledWith(36)
  })

  it('soft drop: giu invia +1 al primo passo', () => {
    const { ctx, comanda } = ctxFinto()
    comanda('sx') // avvia
    comanda('giu')
    expect(ctx.invia.punteggio).toHaveBeenLastCalledWith(1)
  })

  it('pausa: nessun tick finché non si riprende (Review Focus)', () => {
    const { ctx, comanda } = ctxFinto()

    vi.advanceTimersByTime(800 * 5) // I a y=5
    ctx.handle.pausa()
    vi.advanceTimersByTime(60_000) // 75 tick virtuali: senza pausa sarebbe finita
    expect(ctx.invia.fine).not.toHaveBeenCalled()

    vi.advanceTimersByTime(800 * 15) // 5 + 15 = 20 tick reali → prima lock (tick 19)

  - `conferma`: `stato = hardDrop(stato)`; `ctx.invia.punteggio(stato.punti)`; `beep(110, 0.05)`;
